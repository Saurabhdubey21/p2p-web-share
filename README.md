# P2P File Share

A browser-based P2P file sharing app built with React, Node.js, Socket.io and PeerJS. Files transfer directly between browsers with no server storage.

## Tech Stack
- Frontend: React.js, Vite
- Backend: Node.js, Express.js
- Real-time: Socket.io
- P2P: PeerJS (WebRTC)

## Setup
1. Clone the repo
2. cd server and run: npm install then node index.js
3. cd client and run: npm install then npm run dev
4. Open http://localhost:5173 in two tabs
